# MedAssist-AI-Powered-Clinical-Knowledge-Chatbot
Developed an AI-powered Medical Chatbot using Python, LangChain, Pinecone, and Large Language Models (LLMs) to enable context-aware question answering over medical documents using a Retrieval-Augmented Generation (RAG) pipeline. Implemented semantic search, vector embeddings, and an interactive web interface for medical information retrieval.
